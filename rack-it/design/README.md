# rack-it/design

Artboards for the Rack It dark system v2. Drop this folder in at `rack-it/design/`.

| File | What it is |
|---|---|
| `DESIGN.md` | The implementation spec — tokens, live-screen redlines, the ball, legibility, migration order. Read this first. |
| `01-live-11-point-nine.png` | Live scoring, 11-Point-Nine, teal side shooting. The reference frame. 390×844 @2x. |
| `02-legibility.png` | Contrast, sizes and rules for the over-40 eye. |
| `04-live-golden-nine.png` | Golden-Nine: foul row, captioned win columns, ball drop, End mid-hold. |
| `05-new-match.png` | Setup: segmented game picker, one settings card, odds above Start. |
| `06-ratings.png` | Ratings list + live-match strip + tab bar. |
| `07-matches.png` | Match history, no per-row delete. |
| `08-tokens.png` | Colour, type, spacing and target tokens. |

Screens are drawn at 390×844 (iPhone 14/15 logical size), exported at 2x. `01` and `02` carry the
legibility pass; `04`–`08` still show the earlier grey ramp and 13px labels. `DESIGN.md` wins
over the PNGs everywhere.

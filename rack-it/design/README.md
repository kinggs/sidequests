# rack-it/design

Artboards for the Rack It dark system v2. Drop this folder in at `rack-it/design/`.

| File | What it is |
|---|---|
| `DESIGN.md` | The implementation spec — tokens, live-screen redlines, migration order. Read this first. |
| `01-live-11-point-nine.png` | Live scoring, 11-Point-Nine, teal side shooting. 390×844 @2x. |
| `02-live-golden-nine.png` | Live scoring, Golden-Nine: foul row, captioned win columns, ball drop, End mid-hold. |
| `03-new-match.png` | Setup: segmented game picker, one settings card, odds above Start. |
| `04-ratings.png` | Ratings list + live-match strip + tab bar. |
| `05-matches.png` | Match history, no per-row delete. |
| `06-tokens.png` | Colour, type, spacing and target tokens. |

All screens are drawn at 390×844 (iPhone 14/15 logical size), exported at 2x.
Measurements in `DESIGN.md` are the source of truth; the PNGs are the reference render.
